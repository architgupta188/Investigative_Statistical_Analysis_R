# Investigative Statistical Analysis in R

A comprehensive statistical analysis project implemented in **R**, focused on exploratory data analysis, hypothesis testing, statistical modeling, and data-driven insights.

## 📌 Project Overview

This repository contains investigative statistical analysis workflows using R programming. The project demonstrates practical applications of statistics and data analysis techniques including:

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Descriptive statistics
- Hypothesis testing
- Correlation analysis
- Regression modeling
- Data visualization
- Statistical interpretation

The goal of this project is to extract meaningful insights from datasets using statistical methods and reproducible R-based analysis.
